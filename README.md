# 带薪守塔 💢

> 上班摸鱼，带薪守塔 —— 怒砸键盘，硬刚工作怪

一款为「上班摸鱼」场景深度定制的办公室题材**解压泄愤**塔防网页游戏。纯前端、零依赖、秒开、可随时中断、有完整成长体系与 roguelike 局内成长。

## 快速开始

```bash
cd /Users/intoblack/workspace/playGame
python3 -m http.server 8899
# 打开 http://localhost:8899
```

无任何构建步骤。Vue 3 已本地化到 `vendor/`，内网/离线也能玩。

## 玩法

- **世界观**：你是公司里最后的清醒者。用办公神器（咖啡机/绿植/算盘/老板相框/机械键盘/游戏鼠标）抵御工作怪（会议怪/PPT兽/KPI魔王）入侵你的工位。
- **岗位系统**：进关前选择工位身份——👨‍💻程序员 / 📋产品经理 / 🎨设计师 / 🐞测试 / 📣运营 / 💼HR，每个岗位有专属被动（如程序员键盘塔攻速+15%、产品经理开局金币+80、HR 生命+3+开局怒气）与专属人设台词，选择持久化存档。
- **上下游怪物皮肤**：同一只怪在不同岗位眼里是不同的上下游同事——「报表哥布林」在程序员眼里是**PRD修改兽**（需求又变了！），在产品经理眼里是**排期表怪**（排期再压压），在设计师眼里是**需求机器人**（logo放大）。6 岗位 × 12 怪 = 72 套皮肤命名 + 击杀发泄短句，连 Boss 都会改名（程序员打的是「35岁危机」，产品打的是「OKR终魔」，HR 打的是「裁员名单」）。
- **6 系塔 × 4 级升级**：咖啡塔（速攻单体）/ 绿植塔（减速+毒）/ 算盘塔（AOE溅射）/ 老板相框（魔法穿甲+击杀返现）/ **键盘塔**（键帽连射，命中攒怒气，键温叠伤越敲越上头）/ **鼠标塔**（光标点杀必中无视闪避，残血斩杀翻倍）。敌人有物抗/魔抗/闪避/飞行/分裂，逼你换阵。
- **15 关 × 3 章**：新人入职 → 部门风暴 → 年终决战。三星评价（通关/血量≥70%/满血），星级解锁后续关卡。第 5/10/15 关有 Boss：周会巨兽、PPT千页兽、KPI终魔（低血狂暴）。
- **三档难度**：🌱试用期（敌命 -15%）→ 💼正式工（标准）→ 🔥裁员危机（敌命 +45%、金币 -15%、生命减半、**怪带精英词缀**、深夜冷蓝滤镜，本关三星解锁，通关 +3💎）。难度走乘法总线，经济与敌人同步缩放，一份数值三档体验。
- **波间福利 · 三选一（roguelike 核心）**：每波结束从 3 张「福利卡」中选 1 张，24 张卡 × 3 稀有度（普通/稀有/传说），效果**无限叠加**滚出流派：财务自由流、键盘侠流、办公室之王流……连续没抽到传说卡累积幸运值（软保底，Slay the Spire 式）。
- **精英词缀**：裁员危机 / 无尽 12 波后，怪带词缀登场——⚡加速（红色拖尾）/🛡顽固/💚自愈/🧬分裂/💰高薪/🔨硬化/😤狂暴/🔵巨型，高波次出双词缀，词缀怪金框血条 + 头顶徽章。
- **无尽模式**：通关第 15 关解锁，每 5 波一个 Boss，12 波起出词缀怪，本地最高波数记录。
- **每日挑战**：按日期种子生成词条关（全世界摸鱼人同一张卷子），**每天一次机会**，完成得摸鱼券 + streak 递增奖励（🔥连续 3/5/7 天加送 🧊断签保护券），结算可一键复制战绩晒群。
- **摸鱼科技**：摸鱼券 💎 购买永久强化（6 支线 × 3 级，含「键盘侠之魂」怒气强化）。
- **离线收益**：摸鱼猫 🐱 在你离开时替你打工（击退 N 只工作怪），回来领 💎（8 小时封顶，公平设计）。
- **成就 + 称谓**：21 个成就，从「实习摸鱼员」升到「带薪传说」。

## 解压泄愤系统（本作的灵魂）💢

| 玩法 | 说明 |
|------|------|
| 怒气槽 | 击杀 +3、键盘塔命中 +0.8、手动怼击 +6，攒满 100 触发 |
| 💢 怒砸键盘 | 怒气满按 `R`（或点怒气条/HUD 按钮）：全屏敌人受 18% 最大生命伤害 + 晕眩 1.2s，键帽雨从天而降，白领小人冲入画面怒砸键盘，慢动作 + 白闪 + 大震屏 |
| 🖱️ 手动怼击 | 战斗中直接点击敌人「怼一下」：造成 6% 最大生命伤害 + 短暂击退，0.75s 冷却，是打工人亲手泄愤的快乐（Boss 只掉 2% 且不击退） |
| Boss 处刑 | Boss 死亡瞬间慢动作 0.7s + 白闪 + 碎片喷发 + 怒气 +40 |
| 死亡碎裂 | 每只工作怪死亡喷出键帽/纸片碎片，物理引擎下落弹跳 |
| 连击红晕 | 连击 ≥12 画面边缘泛起怒气红光，越连越红 |
| 发泄文案系统 | 击杀怪飘出岗位专属短句（打掉「PRD修改兽」飘「需求又变了」）；手动怼击随机「讲点武德/锅还你/已读乱回」；每波开场横幅随机职场吐槽（「这个需求很简单」「对齐一下颗粒度」）；结算页发泄语；主页职场黑话滚动弹幕 |

## 摸鱼特化

| 功能 | 说明 |
|------|------|
| 🕶️ 老板键 | 按 `Esc` 或点右上角按钮，整页瞬间变成「星云 ERP · 2026 Q4 经营数据核对表」，连浏览器标签页标题都是工作风的 |
| 失焦自动伪装 | 切走窗口自动暂停 + 自动套上伪装屏（可在主页关闭） |
| 波间任意暂停 | 空格暂停，任何时刻关掉页面，进度都在（localStorage 自动存档） |
| 2 倍速 + 自动开波 | 摸鱼时间宝贵 |
| 快捷键 | `1-6` 造塔 · `R` 泄愤大招 · `空格` 开波/暂停 · `Esc` 老板键 |
| 🎁 惊喜宝箱 | 波间随机掉落，12 秒内点开：金币 / 全员咖啡 buff / 摸鱼券 |

快捷键注意：`Esc` 同时是「进伪装/出伪装」的开关；伪装屏上任意点击右下角「·」也可返回（返回后游戏保持暂停）。

## 上瘾模型（Hooked 闭环，都有研究依据）

**触发**（上班无聊/压力 → 收藏夹一点即开 + 同事群战绩晒图）→ **行动**（0.5 秒恢复战局，单键造塔）→ **可变奖赏** → **投入**（选卡攒流派/升科技/护 streak/差一颗星的关卡）→ 投入加载下一个触发：「明天上班，再来一把。」

1. **60 秒核心循环 + 波间三选一**：看怪 → 造塔 → 击杀反馈 → **选卡变强**——每波一个变率奖励节点（StS/明日方舟验证的最强 roguelike 引擎）。
2. **可变比率奖励三层**：宝箱三选一随机（Nagle 2014）、连击金币雨（每 8-14 连击随机触发）、福利卡稀有度 60/30/10 + 软保底。
3. **近失效应**：结算页高亮「只漏 N 只就是三星」（Larche 2017：near-miss 是继续玩冲动最强诱因）；怒气 88% 后充能加速，制造「就差一点」。
4. **损失厌恶 + 复仇**：失败不清进度，白得 1 张稀有卡 +15% 金币复仇再战；streak 断签保护券（Duolingo 式）。
5. **微会话设计**（NN/g）：每波 20-40 秒天然断点、随时关页零惩罚、回场礼包「摸鱼猫击退了 N 只怪」。
6. **元进度**：星级 → 难度解锁 → 科技树 → 成就称谓 → streak，多层长线目标（Larche 2020 心流）。
7. **85% 规则难度分层**：试用期/正式工/裁员危机三档，让不同水平玩家都落在心流通道（Wilson 2019）。

## 数值架构（关键决策）

- 敌人 HP：`base × 关卡系数 × (1 + 0.22(w-1) + 0.010(w-1)²)` —— 阻尼二次增长（纯指数会失控，YYZ 实测教程结论）
- **经济与难度同步缩放**：赏金/波次奖金/初始金币都随关卡系数缩放，保证后期关数学上可解
- Boss 血量只乘关卡系数 + 线性波次项，不叠波内二次项
- 速度曲线砍平（1 → 1.13）：速度压缩反应窗口，不是好的难度维度；血量才是
- 验证方式：无头浏览器自动模拟通关（造塔+升级策略），L1-L5 满星可通，L10/L15 为极限挑战关（真人需针对性布阵 + 科技成长），无尽 19 波

## 美术（程序化精灵系统）

零外部图片资源：所有素材在加载时用 Canvas 2D 手绘矢量函数预渲染到离屏画布（2x 超采样），运行时直接贴图。

- **风格**：深描边卡通 chibi 风 + 办公室主题（咖啡杯炮台、仙人掌、算盘、老板相框；实习生/报表哥布林/HR 盾姐/周会恐龙/KPI 恶魔等 12 怪）
- **场景**：办公室夜景地毯格纹 + 顶灯光池 + 窗光斜斑 + 暗角；路径为地毯跑道（描边+接缝+流动虚线）；每关用种子随机在合法格位摆放饮水机/复印机/文件柜/碎纸机等装饰（静态层整关只画一次）
- **反馈**：塔开火后坐+枪口闪光、敌人走路挤压弹跳+受击白闪（白色剪影，跨浏览器）、追踪弹曳光、抛物算珠旋转、Boss 顶部血条带头像
- **HUD**：塔卡/下一波预告/塔面板头像均由 `Sprites.stamp` 贴同款精灵，与战场画风统一
